# Tennis SillaCoach — aplicación completa
1. Extrae este ZIP. Publica la carpeta que contiene index.html en un alojamiento estático HTTPS, por ejemplo GitHub Pages o Netlify Drop.
2. En Android, abre la dirección HTTPS en Chrome.
3. Pulsa Instalar en Android si aparece en la app. También puedes usar el menú de Chrome: Añadir a pantalla de inicio → Instalar.
4. Abre la aplicación al menos una vez con conexión para habilitar su reapertura sin conexión.
Para probar en Windows, abre PowerShell en la carpeta extraída y ejecuta py -m http.server 8000 --bind 127.0.0.1. Abre http://localhost:8000 en el mismo computador.
Los partidos e informes se guardan en el navegador del dispositivo. Borrar los datos del sitio borra el historial.
